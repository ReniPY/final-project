Директория `web` содержит файлы фронтенда.

Директория `pkg` содержит следующие директории 
`api` - содержит обработчики апи запросов и правила 
`db` - содержит фаилы базы данных и фаил методов работы с задачами
`server` - содержит фаил веб сервера
